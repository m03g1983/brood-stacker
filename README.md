# Brood Stacker

Lua-скрипт для Umbrella (UCZone API v2.0): паучки Broodmother сами стакают лесные кемпы, игрок не теряет контроль над героем.

## Установка

Положите [`brood_stacker.lua`](brood_stacker.lua) в `%cheat_dir%/scripts`. Новые версии появляются здесь, версия указана в начале файла и на панели в игре.

## Меню

`Heroes → Hero List → Broodmother → Автостак`

- Кнопка «Выключить скрипт», переключатель и бинд вкл/выкл
- Режим: авто (ближайшие кемпы) или выбранные кемпы
- Паучков на кемп, кемпов максимум, типы кемпов, только свой лес
- «Не брать выделенных паучков» — выделенных вами паучков скрипт не трогает
- Шестерёнка у «Включить»: тайминги удара по типам кемпов, отступ ожидания для среднего, «выходить не раньше», дистанция увода, лимит стаков и др.

## Панель на экране

Показывает стаки по кемпам (точки = стаки, состояние: в пути / ждёт / агр / увод / готово) и подсказку, когда создавать паучков. Перетаскивается мышью, пока открыто меню чита, и прилипает к краям экрана. Кнопка ВКЛ/ВЫКЛ в шапке.

## Как работает

- Каждый паучок выходит к кемпу в своё время в зависимости от расстояния, но не раньше :40.
- В нужную секунду бьёт крипа и уводит его в свою точку отвода, чтобы к xx:00 кемп был пуст.
- Кемп с 3 стаками больше не стакается.
- Если паучок умрёт до конца стака, на кемп идёт ещё один, у кого больше времени жизни.
- Приказ игрока паучку отпускает его на время из настроек.
- Напоминание создать паучков (только после прокачки ульты).
